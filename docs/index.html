Mac 版 GitHub

拖入 DJI 视频或文件夹

自动识别每段视频是 D-Log 还是 D-Log2

视频不会上传，全部在你的浏览器里读取，只读取文件末尾的元数据，几百 MB 的视频也是瞬间完成。
手机上请从「文件」里选择原始视频，从相册选择可能会被系统转码而丢失信息。

读取 DJI 写入视频元数据的 com.dji.camera.ColorGammaSxS 字段，结果确定，不靠画面猜测。
